# Инструкция по тестовому запуску проекта в GitHub Codespaces

Эта инструкция описывает, как быстро развернуть, протестировать и отладить проект **DurakProekt** в среде **GitHub Codespaces** или в локальном окружении Node.js.

---

## 1. Что есть в проекте

| Компонент | Путь | Описание |
| :--- | :--- | :--- |
| **Игровой движок** | `src/game.js`, `src/deck.js`, `src/rules.js` | Чистая логика партии в переводного дурака (без зависимостей). |
| **Боты** | `src/bots/simpleBot.js` | Простой бот с базовыми эвристиками. |
| **CLI / Симуляция** | `src/cli/playVerbose.js`, `src/cli/simulate.js` | Консольные скрипты для прогона партий и проверки стабильности. |
| **Мультиплеерный сервер** | `server/index.js`, `server/rooms.js` | HTTP/WebSocket сервер для комнат, лобби и авто-подмены ботов при обрыве связи. |
| **Тестовый клиент** | `server/test-client.html` | Простой HTML-клиент для проверки WS-соединения и игры через сервер. |
| **Визуализация (клиент)** | `docs/index.html` (и `visual/index.html`) | Веб-интерфейс игры: просмотр ботов и интерактивный режим. |

---

## 2. Быстрый запуск в GitHub Codespaces

1. Перейдите в репозиторий на GitHub и нажмите кнопку **Code** -> вкладка **Codespaces** -> **Create codespace on main** (или вашей ветке).
2. Дождитесь инициализации контейнера и установки зависимостей (`npm install`).
3. В терминале Codespaces запустите сервер:
   ```bash
   npm start
   ```
4. Перейдите на вкладку **Ports** в нижней панели Codespaces.
5. Для порта `8080` нажмите на иконку глобуса или скопируйте Public URL (`https://...-8080.app.github.dev`). Убедитесь, что видимость порта (**Port Visibility**) установлена как **Public** (иначе WebSocket и браузерные запросы могут блокироваться авторизацией GitHub).

---

## 3. Проверка движка и ботов (CLI)

Вы можете протестировать логику игры в консоли без запуска сервера:

```bash
# Подробный лог одной партии ботов (2 игрока, колода 24 карты)
node src/cli/playVerbose.js 2 24

# Массовый прогон (1000 партий) для проверки на зависания и ошибки
node src/cli/simulate.js 1000 4 36
```

## 4. Переменные окружения сервера

Сервер поддерживает следующие настройки через переменные окружения:

| Переменная | По умолчанию | Описание |
| :--- | :--- | :--- |
| `PORT` | `8080` | Порт HTTP/WS сервера |
| `BOT_TAKEOVER_MS` | `3000` | Время ожидания игрока при обрыве связи до подмены ботом |
| `BOT_MOVE_DELAY_MS` | `800` | Задержка хода бота для наглядности |
| `ROOM_CLEANUP_GRACE_MS` | `10000` | Время жизни пустой комнаты / после завершения партии |

Пример запуска с кастомными настройками:
```bash
PORT=3000 BOT_MOVE_DELAY_MS=400 npm start
```

## 5. Чек-лист тестирования

- [ ] Консольные скрипты (`playVerbose.js`, `simulate.js`) выполняются без ошибок.
- [ ] Сервер успешно запускается (`npm start`).
- [ ] Открыв корневой URL сервера (`/`) в браузере, вы видите тестовый клиент (`server/test-client.html`), а WebSocket-соединение устанавливается автоматически (`wss://...`).
- [ ] Можно создать комнату, подключиться из второй вкладки и провести тестовую партию.
- [ ] При закрытии вкладки одного из игроков срабатывает таймаут, и управление переходит к боту.
- [ ] Страница `/visual` (`docs/index.html`) открывает визуальный интерфейс игры.

---

## 6. Возможные проблемы и их решение

1. **WebSocket не подключается / Ошибка 403 / CORS:**
   * Проверьте, что порт `8080` в Codespaces имеет статус **Public** (правый клик по порту в панели Ports -> Port Visibility -> Public).
2. **Зависание партии ботов (`MAX_STEPS`):**
   * В редких конфигурациях игра может упираться в защитный лимитер ходов. Если это воспроизводится стабильно, создайте issue с логом `playVerbose.js`.
